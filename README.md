# 企业内部智能知识库问答平台 | AI PM模拟项目
> 通用AI产品经理作品集项目，聚焦企业级RAG知识库产品设计，解决企业文档分散、信息查询低效的痛点。

## 🎯 项目背景
企业内部文档分散在OA、邮件、共享盘等多平台，员工查找信息平均耗时超10分钟；新员工依赖人工答疑，培训成本高、效率低。本项目设计了面向企业员工的智能知识库问答平台，支持带引用溯源的精准问答、部门级权限隔离等核心功能。

## 📁 核心产出
- 完整产品需求文档：[PRD.md](./PRD.md)
- 核心业务流程图（见PRD内）
- 竞品分析与风险优化方案

## 🛠️ 产品核心模块
1.  **知识库管理**：文档上传、分类管理、部门级权限控制
2.  **智能问答**：多轮对话、回答引用溯源、结果反馈
3.  **会话管理**：历史对话保存、导出与删除
4.  **管理员后台**：用户权限配置、高频问题统计

## 💡 我的产品思考
- 针对企业场景，强化了权限隔离与数据安全设计，解决企业用户的核心顾虑
- 为降低模型幻觉风险，设计了「引用溯源+人工审核」双重保障机制
- 参考主流AI办公产品，补充了异常场景的用户体验优化方案
