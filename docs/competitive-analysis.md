### 2.2 关键差异点

**Glean (行业标杆)**
- 优势：权限感知搜索是杀手功能，能跨100+应用搜索
- 劣势：定价高（$100+/user/月），国内市场几乎不可用
- 启示：权限管理是企业的刚需，设计时应预留扩展接口

**Notion AI**
- 优势：零门槛，写作+搜索无缝融合
- 劣势：仅限Notion生态，不支持外部文档
- 启示：用户体验的流畅度决定了产品采纳率

**Dify (最接近的竞品)**
- 优势：可视化编排引擎灵活度极高，社区生态好
- 劣势：定位过泛（万能平台），知识库场景不够聚焦
- 启示：我们的差异化在于"专注企业知识库场景，做深做透"

**FastGPT**
- 优势：开箱即用的知识库问答，中文支持好
- 劣势：功能相对单一，缺少权限管理和评估体系
- 启示：开箱即用很重要，但需要增加企业级功能形成壁垒

## 3. 本项目的差异化定位

### 3.1 定位陈述
> 面向中国企业的、开源的、注重评估和追溯的企业知识库RAG系统。不被平台锁定，数据完全自主可控。

### 3.2 核心差异化

1. **评估驱动**：内置RAGAS评估体系，让检索质量可量化（竞品均无此能力）
2. **引用溯源做到极致**：每条回答精确标注到源文档+源段落+页码
3. **中文检索深度优化**：BGE中文Embedding + BM25中文分词
4. **开源自建可控**：数据不出企业，0供应商锁定风险
5. **PM视角的完整文档**：PRD+架构+评估报告，体现产品完整性

### 3.3 目标客群
- 中国中小型企业（50-500人），需要知识库检索但无力购买Glean
- 对数据安全敏感的金融/法律/医疗企业
- 希望通过开源方案快速验证RAG价值的创新团队

---

## 4. 市场机会

- 中国企业知识管理市场年增速约30%（艾瑞咨询2023）
- 大部分企业仍在使用传统关键词搜索（如Confluence内置搜索）
- LLM+RAG的技术红利窗口期仍存在（2024-2025）
- 开源+私有化部署模式在中国政企市场有独特优势

## 5. 结论

本项目不会与大厂产品正面竞争，而是聚焦 **"企业知识库RAG的MVP标准答案"** 这一定位——一个产品文档完整、代码清晰、可快速部署的开源方案，既能作为企业选型前的PoC模板，也能作为AI PM的标杆作品展示。
