## 2. 核心组件设计

### 2.1 文档摄入管道 (Ingestion Pipeline)

**流程**: 原始文件 → 格式解析 → 文本清洗 → 文档切片 → 向量化 → 向量入库 + BM25索引

**支持格式**:
- PDF: 使用 pypdf 提取文本
- DOCX: 使用 python-docx 提取文本
- TXT/Markdown: 直接读取

**切片策略** (configurable):
```python
class ChunkingConfig:
    chunk_size: int = 512      # 每个chunk的token数
    chunk_overlap: int = 50     # chunk之间的重叠token数
    separators: List[str] = [   # 分割符优先级
        "\n## ", "\n### ",      # Markdown标题
        "\n", "。", ".", " "    # 段落和句子
    ]
    include_metadata: bool = True  # 保留文档名、页码等元数据
```

### 2.2 向量存储

**选用 ChromaDB**，理由：
- 轻量级，零配置，适合MVP快速验证
- 支持metadata filtering（按知识库ID、文档名过滤）
- 支持持久化存储
- 可平滑迁移到Milvus（生产环境）

**数据模型**:
```
ChromaDB Collection: "knowledge_base"
├── id: str                 # 唯一标识 (uuid)
├── embedding: float[1024]  # BGE-M3 嵌入向量
├── document: str           # chunk文本内容
├── metadata:
│   ├── kb_id: str          # 知识库ID
│   ├── doc_id: str         # 文档ID
│   ├── doc_name: str       # 文档名称
│   ├── page: int           # 页码
│   ├── chunk_index: int    # 切片序号
│   └── created_at: str     # 创建时间
```

### 2.3 混合检索

**融合策略**: 加权求和

```
final_score = α × vector_score + (1-α) × bm25_score
α = 0.7 (默认，可配置)
```

- 向量检索 (Semantic): 理解语义相似性，处理同义词和模糊意图
- BM25检索 (Lexical): 精确关键词匹配，处理专业术语和人名
- 融合后召回 Top-20，送入重排序

### 2.4 重排序

使用 **BGE-Reranker-Base** 做精排：
- 输入：query + 每个候选chunk
- 输出：相关性分数(0-1)
- 从Top-20精排到Top-5，大幅提升准确率

### 2.5 LLM生成

**Prompt模板**:
```
你是一个专业的企业知识库助手。请根据以下参考资料回答用户问题。

## 规则
1. 仅使用参考资料中的信息回答
2. 如果资料不足以回答，请明确说"根据现有资料无法回答"
3. 回答时引用来源编号，如 [1][2]
4. 保持回答简洁、专业

## 参考资料
[1] {chunk_1}
[2] {chunk_2}
...

## 用户问题
{question}

## 回答
```

## 3. 技术选型理由

| 技术 | 选择 | 备选 | 选型理由 |
|------|------|------|---------|
| 后端框架 | FastAPI | Django/Flask | 异步高性能、自动Swagger文档、类型安全 |
| RAG框架 | LlamaIndex | LangChain | 企业功能更完善（IngestionPipeline、MetadataFilter原生支持） |
| 向量库 | ChromaDB | Milvus/Pinecone | 零配置、Python原生、MVP快速验证 |
| Embedding | BGE-M3 | OpenAI/text2vec | 开源免费、中文效果SOTA、支持本地部署 |
| 前端 | Next.js | Vue/纯HTML | 展示全栈能力、生态丰富、部署方便 |
| 大模型 | DeepSeek | GPT-4/通义千问 | 中文效果好、成本低、OpenAI兼容格式 |

## 5. 数据流图

```
用户提问 "年假有几天？"
    │
    ▼
┌──────────────┐
│ 1. Query预处理 │  → 分词、纠错、意图识别(预留)
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 2. 混合检索    │  → 向量检索(ChromaDB) + BM25检索
│    召回Top-20  │     融合策略: 0.7×vector + 0.3×bm25
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 3. 重排序      │  → BGE-Reranker对Top-20精排
│    取Top-5     │     输出相关性分数
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 4. LLM生成    │  → 构建Prompt (system + contexts + question)
│               │     DeepSeek/通义千问生成回答
│               │     附带引用来源标号
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 5. 响应格式化  │  → JSON: { answer, sources[], elapsed_ms }
└──────────────┘
```
