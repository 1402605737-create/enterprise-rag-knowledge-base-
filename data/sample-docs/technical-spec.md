# 云帆AI平台 v3.0 — 技术架构说明书

## 1. 平台概述

云帆AI平台是一个企业级AI能力中台，提供模型管理、知识库构建、智能客服、数据分析等核心能力。v3.0版本于2024年Q2发布，实现了从单体架构到微服务架构的全面升级。

## 3. 知识库服务详细设计

### 3.1 文档摄入流程
1. **文档上传**：支持PDF/DOCX/TXT/Markdown/HTML格式
2. **格式解析**：使用Unstructured库统一抽取文本
3. **文档切片**：
   - 默认chunk_size=512 tokens, overlap=50 tokens
   - 支持语义切片（基于段落和标题）
   - 支持表格和图片的独立处理
4. **向量化**：使用BGE-M3模型，输出1024维向量
5. **入库**：向量存入Milvus，元数据存入PostgreSQL

### 3.2 检索策略
- **混合检索**：向量相似度(0.6) + BM25关键词匹配(0.4)
- **重排序**：使用BGE-Reranker-Large进行精排
- **Top-K**：粗排召回50条，精排保留5条
- **检索优化**：支持元数据过滤、时间衰减、文档重要性加权

### 3.3 性能指标
| 指标 | 目标值 | 当前值 |
|------|--------|--------|
| 文档处理吞吐 | 100页/分钟 | 85页/分钟 |

## 4. API接口规范

### 4.1 知识库管理接口
```yaml
POST   /api/v1/knowledge-bases           # 创建知识库
GET    /api/v1/knowledge-bases           # 查询知识库列表
DELETE /api/v1/knowledge-bases/{id}      # 删除知识库

POST   /api/v1/knowledge-bases/{id}/documents  # 上传文档
DELETE /api/v1/knowledge-bases/{id}/documents/{doc_id}  # 删除文档
GET    /api/v1/knowledge-bases/{id}/documents       # 查询文档列表
```

### 4.2 检索问答接口
```yaml
POST   /api/v1/chat/completions          # 对话接口（含RAG）
  request:
    query: "string"                      # 用户问题
    knowledge_base_ids: ["string"]       # 知识库ID列表
    top_k: 5                             # 召回数量(1-20)
    stream: true                         # 是否流式输出
  response:
    answer: "string"                     # 生成的回答
    sources: [{                          # 引用来源
      "document_name": "string",
      "chunk_text": "string",
      "page": 1,
      "score": 0.95
    }]
```

## 5. 部署架构

### 5.1 生产环境
- **集群规模**：3个Master节点 + 10个Worker节点
- **GPU资源**：4×NVIDIA A100-80GB（用于模型推理）
- **存储**：Ceph分布式存储，总容量50TB
- **网络**：万兆内网，BGP多线出口

### 5.2 容灾方案
- **同城双活**：深圳主集群 + 广州备集群
- **RPO**：<1分钟（数据库主从同步）
- **RTO**：<30分钟（自动故障切换）
- **备份策略**：每日全量备份，每6小时增量备份

### 5.3 安全措施
- 传输加密：TLS 1.3
- 数据加密：AES-256-GCM（静态数据）
- 访问控制：RBAC + ABAC混合模型
- 审计日志：全量API调用记录，保留180天
- 渗透测试：每季度一次，由外部安全团队执行
