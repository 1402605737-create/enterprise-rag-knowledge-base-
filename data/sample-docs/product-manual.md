# 云帆智能客服系统 v2.5 — 产品使用手册

## 产品简介

云帆智能客服系统是一款基于大语言模型的智能客服解决方案，支持多渠道接入、意图识别、知识库问答、人工转接等功能，为企业提供7×24小时自动化客户服务。

## 快速入门

### 系统要求
- 浏览器：Chrome 90+、Edge 90+、Safari 14+
- 网络：需接入互联网，建议带宽≥10Mbps
- 推荐分辨率：1920×1080

### 账号开通
1. 联系销售或客户成功经理获取开通链接
2. 完成企业认证（营业执照 + 法人身份验证）
3. 管理员创建子账号并分配权限
4. 完成新手引导（约需15分钟）

## 核心功能

### 1. 知识库管理
- **导入方式**：支持手动录入、批量导入（Excel/CSV）、API同步
- **知识类型**：FAQ问答对、文档型知识、流程型知识、多媒体知识
- **知识审核**：支持多级审核流程，草稿→审核→发布
- **版本管理**：保留历史版本，支持回滚

### 2. 对话机器人
- **意图识别**：基于深度学习的意图分类模型，准确率95%+
- **多轮对话**：支持上下文理解，可配置对话流程（可视化画布编排）
- **答案生成**：支持知识库检索、FAQ匹配、大模型生成三种模式
- **语气风格**：支持自定义机器人人设和语气

### 3. 人工客服
- **智能路由**：根据用户问题自动分配给最合适的客服
- **辅助回答**：客服输入问题时，AI自动推荐答案
- **会话接管**：用户可随时从机器人对话切换至人工
- **知识推荐**：人工客服界面实时展示相关知识

### 4. 数据分析
- **会话分析**：会话量、响应时间、解决率统计
- **用户画像**：问题偏好、活跃时段、满意度分析
- **热点挖掘**：自动发现高频问题和新兴话题
- **客服绩效**：在线时长、响应速度、满意度评分

## 配置指南

### 机器人设置
```
1. 导航至：设置 → 机器人管理 → 新建机器人
2. 填写机器人名称、头像、欢迎语
3. 选择关联的知识库
4. 配置意图识别策略（优先级：FAQ匹配 > 知识库检索 > LLM生成）
5. 设置未知问题处理方式（引导人工 / 转留言 / 默认回复）
6. 保存并发布
```

### FAQ配置
1. 导航至：知识库 → FAQ管理
2. 点击"添加FAQ"
3. 填写标准问题和标准答案
4. 添加相似问法（至少3条，推荐10条以上）
5. 设置标签和分类（用于统计和路由）
6. 提交审核

## 最佳实践

### 知识库优化
- FAQ标准问题应覆盖用户高频提问的80%
- 每条FAQ建议添加10-20条相似问法，提高命中率
- 定期分析未命中日志，补充新FAQ
- 知识库内容保持更新，删除过时信息

### 机器人调优
- 初期使用FAQ匹配为主，逐步增加LLM生成比例
- 监控"未知问题"率，目标控制在5%以下
- 分析用户负面反馈，持续优化回答质量
- 行业专有名词添加到自定义词典

## 常见问题

**Q：知识库最多支持多少条知识？**
A：标准版10万条，企业版100万条，旗舰版不限量。

**Q：支持哪些语言的机器人？**
A：支持中文、英文、日文、韩文、法文、西班牙文等20+语言。

**Q：如何评估机器人回答质量？**
A：系统自动分析用户反馈（点赞/点踩），并提供人工标注工具。建议每周抽查100条会话进行评估。

**Q：是否支持私有化部署？**
A：支持。企业版和旗舰版支持私有化部署，需要自备GPU服务器（推荐T4及以上）。
